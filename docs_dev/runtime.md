# Runtime and Workspace

## User workspace

The default workspace is:

```text
~/ACEswarm_ws/
```

Override it with `ACESWARM_WS_ROOT`.

```text
ACEswarm_ws/
├── services/
│   ├── aivudaos/
│   │   ├── apps/
│   │   ├── config/
│   │   ├── data/
│   │   └── .tools/caddy/
│   └── aivudaappstore/
│       ├── data/repo.db
│       ├── data/files/
│       ├── data/tmp/
│       └── config/
├── projects/
├── experiments/
├── logs/
└── state/
```

## Local ports

Ports are allocated dynamically on every launch:

```text
AivudaOS Uvicorn       127.0.0.1:<dynamic>
AivudaAppStore Uvicorn 127.0.0.1:<dynamic>
Caddy Gateway          127.0.0.1:<dynamic>
Caddy admin            127.0.0.1:<dynamic>
```

The embedded services do not bind ports 80/443 and do not require Avahi.

## Embedded AivudaOS

ACEswarm launches local AivudaOS with:

```text
AIVUDAOS_EMBEDDED_MODE=1
AIVUDAOS_WS_ROOT=~/ACEswarm_ws/services/aivudaos
```

Embedded mode skips local Avahi and HTTPS hostname coupling while retaining application UI and Caddy route management.

## Caddy Gateway

ACEswarm generates:

```text
~/ACEswarm_ws/services/aivudaos/config/Caddyfile
```

The Gateway:

- proxies the AivudaOS API;
- serves the AivudaOS UI;
- serves installed application UIs;
- loads application routes generated by AivudaOS;
- supports application Caddy routes and WebSockets.

ACEswarm owns the Gateway process lifecycle. Standalone AivudaOS deployment scripts are not used.
